# Global Reach Hub

Build a modern, highly interactive, and ultra-professional import/export & global trade website designed to establish high trust with international clients. Base the primary color palette and visual accenting strictly on the logo's brand colors [Insert Brand Colors / Hex Codes Here, e.g., Navy Blue #0A192F and Vibrant Gold #FFB800], paired with clean neutral backdrops (off-white/dark mode toggles) and glassmorphism UI elements.

### Core Layout & Structure

1. Hero Section (Interactive & High-Impact):

- Dynamic, full-width hero header with subtle animated vector background (e.g., connected global trade routes or interactive globe).

- Clear value proposition headline with bold typography, a brief dynamic subtext, and twin CTAs: "Request a Quote" (Primary Button) and "Explore Commodities" (Secondary Ghost Button).

- Floating key metrics card (e.g., "50+ Countries Covered", "10K+ Metric Tons Shipped", "99.8% On-Time Delivery") with animated counters.

2. Global Trade Route Visualizer (Interactive Feature):

- An interactive world map or route finder widget where users can select "Origin Country" and "Destination Country" or click on regional hubs to preview trade corridors, estimated transit times, and supported cargo types.

3. Product & Commodity Showcase:

- Grid-based product catalog with filterable tabs (e.g., Agricultural Produce, Minerals, Manufactured Goods, Raw Materials).

- Hover-activated cards with subtle elevation shadows showing high-res imagery, specs, seasonal availability badge, and a direct "Inquire About Product" button.

4. Logistics & Service Capabilities:

- Modern tabbed interface breaking down key services: Freight Forwarding, Custom Clearance, Quality Assurance, and Warehousing.

- Step-by-step interactive timeline explaining the shipment lifecycle (Sourcing -> Logistics -> Quality Control -> Customs -> Final Delivery).

5. Interactive Freight / Quote Calculator:

- Multi-step interactive quote builder widget:

  - Step 1: Select Cargo Category & Estimated Weight/Volume.

  - Step 2: Select Shipping Method (Air Freight, Ocean Freight - FCL/LCL, Overland).

  - Step 3: Origin & Destination selection.

  - Step 4: Contact form submission with instant summary preview before sending.

6. Trust & Compliance Section:

- Grid of international accreditation badges, ISO certifications, trade association logos, and custom clearance compliance seals.

- Interactive FAQ accordion focusing on shipping terms (Incoterms like FOB, CIF, EXW), payment methods (L/C, T/T), and compliance.

7. Global Contact & Inquiry Center:

- Clean dual-column footer layout: Direct WhatsApp/Telegram quick-chat integration on one side, and a multi-field inquiry form with document attachment upload on the other.

- Interactive multi-office locator showing regional office addresses, local time clocks, and contact details.

### Design System & Visual Style

- Style: Ultra-clean corporate tech, glassmorphic cards, polished micro-interactions, subtle gradient borders using primary brand colors.

- Typography: Sharp, highly legible sans-serif type (e.g., Inter or Plus Jakarta Sans).

- Animations: Smooth scroll-triggered fade-ins (Framer Motion style), micro-hover effects on all interactive elements, and sleek modal transitions.

- Fully responsive across desktop, tablet, and mobile. Dark/Light mode theme toggle in the navigation header.
